# Panda Breeder

Client-only Fabric mod for Minecraft Java 1.21.11. Development proceeds in tested milestones: vanilla research, exact genetics, strategy, tracking, UI, overlays, persistence, and integration validation.

## Build

Use JDK 21 or newer: `./gradlew build` (Windows: `gradlew.bat build`). The mod targets Java 21. Install Fabric Loader 0.18.4 or newer and Fabric API 0.141.4+1.21.11. Copy the non-sources JAR from `build/libs` into the client's `mods` directory. No server installation is needed.

## Status

Initial project scaffold; features and validation results are documented as each milestone lands. Minecraft game assets and generated build output are not included in version control.
